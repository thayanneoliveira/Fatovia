# Entrega V6 genérica

O gerador só produz rascunhos. O revisor independente deve baixar o artefato `reel-v6-draft` de uma execução concluída da fábrica na main, verificar o MP4 real, roteiro, fontes, áudio, visual e encerramento, registrar evidências de cada dimensão e hashes. Não emitir aprovação sem acesso e avaliação efetiva. O arquivo `data/reel_review_request.json` deve conter run_id inteiro, scope independent_final_media, reviewer, checked_at ISO com fuso, os seis campos de revisão approved, review_evidence com texto verificável por dimensão, video_sha256, script_sha256, caption_sha256 e logo_sha256. Uma revisão expira após 24 horas. Nunca escreva esse arquivo com aprovação presumida. A entrega valida proveniência, hospeda via Pages e coloca na fila apenas após verificar os bytes públicos. Não chama Meta. O publicador normal continua sendo o único autorizado. A revisão pode ser realizada por um agente independente quando tiver ferramentas para examinar efetivamente o material; sem acesso, registre bloqueio e não aprove. O custo zero continua obrigatório.
